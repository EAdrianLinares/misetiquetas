# Roadmap del Producto

## Objetivo

Definir la evolución funcional del proyecto a lo largo de sus diferentes versiones.

El roadmap representa la dirección del producto, pero podrá modificarse conforme aparezcan nuevas necesidades o cambios en las prioridades.

---

# Versión 1.0 (MVP)

## Objetivo

Permitir transformar información ya existente en etiquetas listas para imprimir de forma rápida y sencilla.

### Funcionalidades

- Ingreso de datos desde texto o CSV.
- Interpretación automática de registros.
- Validación de errores de formato.
- Corrección rápida de registros interpretados.
- Precio y descuento por registro.
- Generación de Código de Barras.
- Generación de Código QR.
- Selección de plantilla.
- Configuración de cantidad de copias.
- Vista previa.
- Impresión.

# Backlog

Las siguientes funcionalidades aún no tienen una versión asignada.

- Modo oscuro.
- Múltiples idiomas.
- Copias de seguridad.
- Sincronización en la nube.
- Impresión remota.
- Integración con impresoras térmicas.
- Estadísticas.
- Reportes.
- Etiquetas con imágenes.
- Códigos NFC.
- IA para diseño automático de etiquetas.

---

# Criterios para incorporar nuevas funcionalidades

Una funcionalidad podrá añadirse al roadmap cuando:

- Aporte valor al usuario.
- No comprometa la simplicidad del producto.
- Tenga una necesidad claramente identificada.
- Sea técnicamente viable.

---

# Mantenimiento del Roadmap

El roadmap deberá revisarse al finalizar cada versión para ajustar prioridades y planificar las siguientes entregas.
