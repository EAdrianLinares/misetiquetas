# Título

Corregir registros interpretados

---

# Historia de Usuario

**Como** usuario del sistema,

**Quiero** corregir los datos interpretados por la aplicación,

**Para** asegurar que la información utilizada para generar etiquetas sea correcta.

---

# Descripción

El sistema deberá permitir al usuario modificar los registros interpretados antes de generar etiquetas.

Esto incluye corregir nombres, códigos, precios y descuentos cuando la interpretación automática no sea del todo precisa.

---

# Precondiciones

* El usuario ya ha pegado la información.
* El sistema ha generado registros interpretados.

---

# Flujo Principal

1. El usuario revisa los registros interpretados.
2. Selecciona un registro para modificar.
3. Actualiza los valores necesarios.
4. El sistema guarda la corrección.
5. El registro corregido queda listo para la generación de etiquetas.

---

# Flujo Alternativo

## FA-01 Valor inválido

Si el usuario ingresa un valor inválido:

* El sistema muestra un mensaje de error.
* El usuario puede corregir el valor antes de continuar.

---

# Reglas de Negocio Relacionadas

* RN-001 Todo registro interpretado debe contener un nombre.
* RN-002 Todo registro interpretado debe contener un código.
* RN-004 El precio debe ser mayor que cero.
* RN-005 El precio con descuento es opcional.

---

# Criterios de Aceptación

### CA-001

El usuario puede modificar un registro interpretado.

---

### CA-002

El sistema valida los cambios realizados.

---

### CA-003

El registro corregido se utiliza en la generación de etiquetas.
