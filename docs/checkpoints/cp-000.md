# Producto Mínimo Viable (MVP)

## Objetivo

Entregar una aplicación funcional que permita generar e imprimir etiquetas de productos de forma rápida y sencilla.

---

# Funcionalidades Incluidas

## Gestión de Productos

* Crear productos.
* Editar productos.
* Eliminar productos.
* Listar productos.

Cada producto contendrá:

* Nombre.
* Código.
* Precio.
* Precio con descuento (opcional).

---

## Configuración de la Generación

El usuario podrá seleccionar:

* Tipo de código:

  * Código de Barras.
  * Código QR.

* Plantilla de impresión.

* Cantidad de copias por producto.

---

## Generación de Etiquetas

La aplicación deberá:

* Generar el código correspondiente.
* Construir las etiquetas.
* Mostrar el nombre del producto.
* Mostrar el precio.
* Mostrar el precio con descuento cuando exista.
* Mostrar el precio original tachado cuando exista descuento.

---

## Vista Previa

Antes de imprimir, el usuario podrá visualizar todas las etiquetas.

---

## Impresión

La aplicación permitirá imprimir todas las etiquetas generadas utilizando la plantilla seleccionada.

---

# Criterios de Aceptación

El MVP será considerado terminado cuando un usuario pueda:

1. Crear uno o varios productos.
2. Seleccionar una plantilla.
3. Elegir Código de Barras o Código QR.
4. Definir la cantidad de copias.
5. Generar todas las etiquetas.
6. Visualizar el resultado.
7. Imprimir las etiquetas.

Todo el proceso deberá completarse sin utilizar herramientas externas.

---

# Funcionalidades Fuera del MVP

No harán parte de la primera versión:

* Inicio de sesión.
* Gestión de usuarios.
* Base de datos.
* Historial de impresiones.
* Catálogo permanente de productos.
* Inventario.
* Ventas.
* Reportes.
* Estadísticas.
* Exportación a Excel.
* Importación desde Excel.
* API pública.
* Múltiples idiomas.

---

# Mejoras Futuras

Las siguientes funcionalidades podrán incorporarse en versiones posteriores:

* Guardar productos.
* Guardar generaciones.
* Reimpresión de etiquetas.
* Múltiples plantillas.
* Personalización de colores y fuentes.
* Logo de la empresa.
* Exportación a PDF.
* Importación masiva desde Excel o CSV.
* Códigos Data Matrix.
* Código GS1-128.
* Integración con sistemas POS o ERP.
* Historial de impresiones.
