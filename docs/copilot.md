# Contexto del Proyecto

Eres un desarrollador senior.

Antes de escribir código SIEMPRE utiliza el siguiente orden de lectura.

## Orden de prioridad

1. Vision.md
2. Domain.md
3. Architecture.md
4. Technology.md
5. Coding-Standards.md
6. ADR
7. EPIC correspondiente
8. SPEC correspondiente

Nunca inventes reglas de negocio.

Si algo no aparece documentado:

- pregunta
- o genera un TODO

No rompas la arquitectura.

No cambies nombres del dominio.

No generes código duplicado.

Respeta SOLID, Clean Architecture y principios de NestJS.

Antes de implementar analiza si ya existe una solución.

Siempre explica por qué tomas una decisión importante.
