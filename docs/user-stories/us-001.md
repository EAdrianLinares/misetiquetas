# Título

Pegar e interpretar datos

---

# Historia de Usuario

**Como** usuario del sistema,

**Quiero** pegar información desde una fuente externa,

**Para** que la aplicación la interprete automáticamente y la convierta en registros listos para generar etiquetas.

---

# Descripción

El sistema deberá permitir ingresar contenido textual desde una fuente externa, como Excel, Google Sheets, CSV u otro texto tabulado o separado por comas.

Una vez recibido, el sistema deberá interpretar la información y generar registros estructurados que puedan utilizarse en la generación de etiquetas.

---

# Precondiciones

* El usuario se encuentra en la pantalla de ingreso de datos.
* El sistema está disponible.

---

# Flujo Principal

1. El usuario pega la información en el área de entrada.
2. El sistema analiza el contenido.
3. El sistema genera registros interpretados.
4. El sistema muestra los registros para revisión.

---

# Flujo Alternativo

## FA-01 Datos incompletos o con formato inválido

Si la información no cumple con un formato reconocible:

* El sistema informa los errores detectados.
* El usuario podrá corregir los datos o repetir el proceso.

---

# Reglas de Negocio Relacionadas

* RN-001 Todo registro interpretado debe contener un nombre.
* RN-002 Todo registro interpretado debe contener un código.
* RN-003 El sistema debe reportar errores de formato durante la interpretación.

---

# Criterios de Aceptación

### CA-001

El usuario puede pegar información y recibir registros interpretados.

---

### CA-002

El sistema detecta y comunica errores de formato cuando aplica.

---

### CA-003

Los registros interpretados quedan disponibles para continuar con la generación de etiquetas.
