SPEC-001

Nombre

Generación de etiquetas

Objetivo

Permitir crear etiquetas imprimibles a partir de registros interpretados desde una fuente de datos.

Entradas

Datos fuente pegados por el usuario

Registros interpretados

Plantilla seleccionada

Tipo de código

Cantidad de copias por registro

Resultado

Hoja lista para imprimir con todas las etiquetas generadas a partir de los registros interpretados.
