# Vision.md

# Visión del Proyecto

## Nombre del proyecto

**Etiquetas**

---

# Propósito

Etiquetas es una aplicación web orientada a convertir información que ya existe en otras herramientas en etiquetas listas para imprimir con el menor esfuerzo posible.

El usuario podrá pegar datos provenientes de Excel, Google Sheets, CSV u otro texto tabulado o separado por comas, y la aplicación interpretará esa información para generar etiquetas.

---

# Problema

Muchos usuarios ya tienen los datos de sus productos en hojas de cálculo o texto, pero reescribir esa información para crear etiquetas consume tiempo, genera errores y dificulta el flujo de trabajo.

Además, el proceso manual de copiar precios, códigos o nombres aumenta la probabilidad de inconsistencias y retrasa la impresión.

---

# Solución

Etiquetas centraliza el proceso en una única experiencia de alto rendimiento.

El usuario podrá:

* seleccionar una plantilla de etiquetas;
* pegar la información fuente;
* interpretar automáticamente los datos;
* revisar una vista previa;
* imprimir las etiquetas.

La aplicación actúa como un transformador de datos hacia etiquetas, sin exigir que el usuario vuelva a registrar cada producto manualmente.

---

# Público objetivo

Esta aplicación está orientada a:

* Tiendas de barrio
* Papelerías
* Ferreterías
* Minimercados
* Librerías
* Tiendas de ropa
* Emprendedores
* Cualquier negocio que necesite imprimir etiquetas a partir de información ya existente.

---

# Objetivos

* Reducir el tiempo necesario para crear etiquetas.
* Simplificar la conversión de información en etiquetas.
* Evitar errores de digitación y de interpretación.
* Permitir imprimir múltiples etiquetas en pocos pasos.
* Ofrecer una interfaz rápida e intuitiva.

---

# Alcance del MVP

La primera versión permitirá:

* Seleccionar una plantilla.
* Pegar datos desde texto o archivos CSV compatibles.
* Interpretar automáticamente la información ingresada.
* Detectar errores de formato o estructura.
* Mostrar una vista previa de las etiquetas.
* Generar etiquetas.
* Imprimir etiquetas.

---

# Fuera del alcance del MVP

Las siguientes funcionalidades no forman parte de la primera versión:

* Gestión de usuarios.
* Inicio de sesión.
* Catálogo persistente de productos.
* CRUD de productos.
* Formularios extensos para registrar productos uno por uno.
* Historial de productos.
* Inventario.
* Ventas.
* Sincronización con sistemas externos.
* Estadísticas.
* Reportes.

---

# Principios del proyecto

* Simplicidad por encima de complejidad.
* Rapidez en la generación de etiquetas.
* Interfaz fácil de aprender.
* Mínima cantidad de pasos para completar una tarea.
* El usuario ya posee la información; la aplicación debe convertirla en etiquetas sin exigirle reescribirla.
* Código organizado siguiendo una arquitectura modular.
* Desarrollo guiado por especificaciones (Spec-Driven Development).

---

# Criterios de éxito

El proyecto será considerado exitoso cuando un usuario pueda:

1. Pegar información desde una fuente externa.
2. Obtener una interpretación automática de los datos.
3. Revisar y corregir de forma rápida los registros detectados.
4. Obtener una vista previa correcta de todas las etiquetas.
5. Imprimir las etiquetas sin necesidad de herramientas adicionales.
6. Completar todo el proceso en pocos minutos.
