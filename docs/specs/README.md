# Specs

Esta carpeta contiene las especificaciones funcionales y técnicas del proyecto.

## Estructura

- specs/functional: especificaciones funcionales por historia o flujo.
- specs/technical: especificaciones técnicas por módulo o feature.
- specs/print-engine: requisitos, diseño y tareas del motor de impresión.
